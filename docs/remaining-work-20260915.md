- [ ] 최근 20건에서 확인한 lawgo CONFLICT 3건 및 2026모683 제52조의 응답 구조 오류를 보존 근거로 조사한다. 별표 등 미지원 형식은 실제 제공 연결을 확인한 경우에만 확장한다.

## 이후 본래의 구조화·검수 목표

1. 기존 60필드의 판시사항·요지·이유를 기반으로 번호/계층을 검증하고 쟁점↔답변↔이유 근거를 연결한다. 단순 필드 추출 완료와 LegalIssueUnit 완성을 구분한다.
2. 원문 위치를 검증한 evidence, provenance, 모호성/실패 사유가 있는 후보를 만든다. 원문↔구조화 결과 비교 UI와 검수 보고서를 구현한다.
3. 후보/GOLD 정책에 따라 JSONL·Parquet 및 버전 고정 dataset manifest를 발행하고 재현·포맷 동등성을 검증한다.
4. Phase 1.5에서 사람의 수정·승인·반려 이력을 자동 결과와 분리해 추가한다.

## 로컬 완료 후 AWS 이관 — 사용자 확정

운영 이관 순서는 **로컬 전체 수집·정리 완료 → 완료 시점 snapshot 고정 → AWS 복사·복원 → 대조 검증 → 서비스 전환**이다. 위 우선순위 1~4 중 수집·보존·정리에 필요한 작업을 먼저 로컬에서 수행한다. 이후의 LegalIssueUnit·GOLD·사람 검수 기능 전체 완성을 AWS 이관의 새로운 선행 조건으로 추가하지 않는다.

1. 이관 기준 시점과 수집 대상 범위를 기록한다. 그 범위의 원문, 60필드 생성·검증, 검색/reader, 이미지·조문 후속 처리를 마친다. 제공 정보 미제공·연결 충돌·취득 실패 등은 명시적인 결과로 남기며 미처리 작업을 완료로 숨기지 않는다. 실제 이관 시 잔여 예외를 검토한다.
2. 실행 중 작업을 완료하거나 checkpoint에 안전하게 멈추고 새 변경 유입을 통제해 DB와 참조 파일의 일관된 이관 snapshot을 만든다. snapshot 이후 변경분을 최초 복사본에 섞지 않는다.
3. PostgreSQL dump, 참조하는 원문·파생 artifact, 이미지 bytes, reader manifest/revision, 60필드 Parquet 및 dataset manifest, 작업·실패·재시도·검증 이력을 복사 대상으로 고정한다. 동결 archive와 외부 보충 파일도 목록에 명시하여 보존 누락을 막는다. 코드·migration·설정 항목의 버전도 기록하되 비밀값을 문서나 로그에 출력하지 않는다.
4. 이미 검증한 로컬 백업·복원 경로를 재사용해 AWS로 복사하고 복사 전후 건수·크기·SHA-256을 확인한다. 로컬 원본·기존 manifest·백업을 삭제하거나 AWS에서 초기 전체 수집을 반복하지 않는다.
5. AWS에서 DB·파일 경로·권한·앱 버전을 맞춰 복원하고 일반 검색→본문→이미지·조문, 관리자 인증·비인가 차단, 단계별 상태를 검증한다. 검증 전 worker가 복원된 대기 작업을 임의 실행하지 않도록 통제한다.
6. 복원 결과를 확인한 뒤 서비스 전환을 진행한다. 복사 이후 추가 수집분 처리와 AWS 이관 후 증보 실행 위치는 별도 운영 결정으로 남긴다. 정기 schedule/cron은 만들지 않는다.

이 기록은 이관 계획이며 AWS 자원 변경·전송·DNS 전환을 지금 실행한 것이 아니다.

## 보관·실서비스 운영과 문서 정합성

- [ ] 최신 파생 자료까지 포함한 백업을 별도 저장소에 복사·hash 검증한다. 기존 전수 로컬 백업·격리 복원 실증은 완료된 기반으로 재사용한다.
- [ ] 관리자 웹에 백업 무결성 검증 실행/결과와 별도 복원 검증 보고서 연결을 추가한다. 부분 백업의 용량·실패 이력은 보존하고 삭제는 명시 승인 없이 하지 않는다.
- [ ] 로컬 수집·정리 완료 시점의 snapshot을 AWS로 이관한 뒤 HTTPS·실제 자원 측정·복원 검증을 수행한다. 과거 PLAN의 평일 운영 예약을 현재 실행 지시로 해석하지 않는다.
- [ ] 과거 시점별 미완료 문구와 현재 구현을 대조해 PLAN/README의 체크리스트를 점진적으로 정합화한다. 과거 실증 이력은 삭제하지 않는다.

최초 계획은 **60필드 대응표 → 신규 23건 소급 처리 → 웹 수집 체인 연결**이었다.
이 단계들은 후속 기록에서 완료됐으므로 다시 착수하지 않는다. 현재 잔여 범위와
실행한 품질 교정은 이 문서 상단 및 최신 기준선 기록을 따른다.
